# 商家店铺设置功能设计规格

> **版本:** v1.0
> **日期:** 2026-06-14
> **状态:** 待实现

---

## 1. 概述

### 1.1 目标

为商家后台添加店铺设置功能，允许商家查看和编辑店铺信息、商家信息。

### 1.2 背景

当前商家后台缺少店铺设置页面，点击"店铺设置"菜单会跳转到C端首页（功能缺失）。

### 1.3 用户角色

- **商家管理员**：可以查看和编辑所有店铺信息

---

## 2. 功能范围

### 2.1 包含的功能

- ✅ 商家信息编辑页面
- ✅ 标签页形式的信息分类
- ✅ 店铺Logo上传（点击上传 + 预览）
- ✅ 营业执照图片上传（1张 + 预览）
- ✅ 表单验证（保存时验证）
- ✅ 每个标签页独立保存
- ✅ 取消/重置功能

### 2.2 不包含的功能

- ❌ 拖拽上传
- ❌ 图片裁剪
- ❌ 自动保存
- ❌ 实时验证
- ❌ 多张营业执照图片
- ❌ 操作日志
- ❌ 草稿/暂存功能

---

## 3. 信息架构

### 3.1 标签页划分

| 标签页 | 字段 | 必填 | 控件类型 | 验证规则 |
|--------|------|------|----------|----------|
| **基本信息** | 店铺名称 | ✅ | Input | 1-50字符 |
| | 店铺Logo | ❌ | 图片上传 | JPG/PNG，≤2MB，建议200x200 |
| | 店铺描述 | ✅ | TextArea | 1-500字符，显示字数统计 |
| **联系信息** | 联系人姓名 | ✅ | Input | 2-20字符 |
| | 联系电话 | ✅ | Input | 手机号格式（1[3-9]\d{9}） |
| | 店铺地址 | ✅ | Input | 5-100字符 |
| **营业资质** | 营业执照号 | ✅ | Input | 15-20位数字和字母 |
| | 营业执照图片 | ❌ | 图片上传 | JPG/PNG，≤5MB |
| **店铺展示** | 营业时间 | ✅ | Input | 如：09:00-21:00 |
| | 扩展字段 | ❌ | 预留 | 后续扩展 |

## 4. 交互设计

### 4.1 页面布局

```
┌─────────────────────────────────────────────────────────┐
│  店铺设置                                    [商家头像] │
├─────────────────────────────────────────────────────────┤
│  [基本信息] [联系信息] [营业资质] [店铺展示]            │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────┐   │
│  │  基本信息                                       │   │
│  │  ─────────────────────────────────────────────  │   │
│  │  店铺名称 *  [________________________]         │   │
│  │                                                 │   │
│  │  店铺Logo    [Logo预览]  [更换Logo]             │   │
│  │             建议尺寸：200x200px                  │   │
│  │                                                 │   │
│  │  店铺描述 *  [________________________]         │   │
│  │              [________________________]         │   │
│  │              0/500                              │   │
│  │                                                 │   │
│  │  [取消]                        [保存基本信息]   │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 4.2 交互流程

#### 4.2.1 编辑流程

```
用户点击"店铺设置"
       ↓
显示第一个标签页（基本信息）
       ↓
用户修改表单内容
       ↓
点击"保存基本信息"
       ↓
触发验证
       ↓
    ┌──────────────┐
    │  验证通过？   │
    └──────────────┘
      ↓ 是        ↓ 否
  提交数据    高亮错误字段
      ↓        显示错误提示
  显示成功提示
      ↓
  更新本地状态
```

#### 4.2.2 取消流程

```
用户修改表单内容
       ↓
点击"取消"
       ↓
弹出确认对话框（如果有修改）
       ↓
    ┌──────────────┐
    │  确认取消？   │
    └──────────────┘
      ↓ 是        ↓ 否
  恢复原始数据  继续编辑
      ↓
  关闭提示
```

#### 4.2.3 图片上传流程

```
点击"更换Logo"按钮
       ↓
弹出文件选择对话框
       ↓
用户选择图片文件
       ↓
    ┌──────────────┐
    │  文件有效？   │
    └──────────────┘
      ↓ 是        ↓ 否
  显示预览    显示错误提示
       ↓
  用户可重新选择或保存
```

### 4.3 表单验证

| 字段 | 验证规则 | 错误提示 |
|------|----------|----------|
| 店铺名称 | 必填，1-50字符 | "请输入店铺名称" |
| 店铺描述 | 必填，1-500字符 | "请输入店铺描述" |
| 联系人姓名 | 必填，2-20字符 | "请输入联系人姓名" |
| 联系电话 | 必填，手机号格式 | "请输入正确的手机号" |
| 店铺地址 | 必填，5-100字符 | "请输入店铺地址" |
| 营业执照号 | 必填，15-20位 | "请输入正确的营业执照号" |
| 营业时间 | 必填 | "请输入营业时间" |

### 4.4 状态反馈

| 操作 | 成功反馈 | 失败反馈 |
|------|----------|----------|
| 保存基本信息 | "保存成功" Toast | 显示错误字段 + Toast |
| 保存联系信息 | "保存成功" Toast | 显示错误字段 + Toast |
| 保存营业资质 | "保存成功" Toast | 显示错误字段 + Toast |
| 保存店铺展示 | "保存成功" Toast | 显示错误字段 + Toast |
| 上传图片 | 显示预览 | "上传失败" Toast |

## 5. 技术架构

### 5.1 前端组件结构

```
src/pages/Merchant/Settings/
├── index.tsx                 # 店铺设置主页面
├── MerchantInfoForm.tsx      # 商家信息表单（联系信息 + 营业资质）
└── ShopInfoForm.tsx          # 店铺信息表单（基本信息 + 店铺展示）
```

### 5.2 状态管理

使用现有的 `merchantAuthSlice`：

- `merchant`: 商家信息对象
- `loading`: 加载状态
- `error`: 错误信息

新增 Action：
- `updateMerchantInfoAsync`: 更新商家信息

### 5.3 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | /api/merchant/info | 更新商家信息 |

请求体：
```json
{
  "name": "萌宠宠物服务中心",
  "logo": "https://...",
  "description": "...",
  "contactName": "张老板",
  "contactPhone": "13600136000",
  "address": "...",
  "businessLicense": "...",
  "businessLicenseImage": "https://...",
  "businessHours": "09:00-21:00"
}
```

响应：
```json
{
  "code": 0,
  "message": "success",
  "data": { /* 更新后的商家信息 */ },
  "timestamp": 1718352000000
}
```

## 7. UI 规范

### 7.1 设计风格

- 遵循现有商家后台的设计风格
- 使用 Ant Design 6 组件库
- 主色调：#FF6B35（橙色）
- 圆角：8px（按钮、输入框）

### 7.2 响应式设计

- 支持桌面端（≥1024px）
- 标签页在窄屏时可滚动

### 7.3 无障碍

- 所有表单字段有 label
- 必填字段有 * 标记
- 错误信息使用 aria-describedby 关联

## 10. 风险与限制

### 10.1 已知限制

- 文件上传使用占位符 API，实际需要配置真实的上传接口
- 暂不支持图片裁剪功能
- 暂不支持多张营业执照图片

### 10.2 后续优化

- 集成真实的文件上传服务
- 添加图片裁剪功能
- 支持更多类型的资质图片
